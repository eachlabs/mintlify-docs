---
title: "Docs search MCP"
description: "Let your AI app search the each::labs documentation."
---

The each::labs documentation has its own MCP server. Add it to an AI app, and the app can search these pages and read them while it answers your questions: about the API, models, workflows, webhooks or billing.

```
https://docs.eachlabs.ai/mcp
```

Add this address as a remote MCP server in any app that supports MCP. No sign-in or API key is needed, because the documentation is public.

<Note>
This server only searches the documentation. It does not run models or workflows and does not touch your account. To generate images, video, music or voice from your AI app, use the [each::labs MCP server](/mcp-server) at `https://mcp.eachlabs.ai/mcp`.
</Note>

The address is meant for MCP apps. Opening it in a browser shows a short description of the server in JSON, not a page.
