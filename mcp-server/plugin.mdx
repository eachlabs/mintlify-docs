The each::labs plugin adds each::labs to Claude and Codex in one step. It bundles two things:

| Part | What it is |
| --- | --- |
| Connector | The hosted each::labs MCP server at `https://mcp.eachlabs.ai/mcp`, with the model catalog, `run_model`, the workflow tools, the video tools and the cards. The [MCP Server](/mcp-server#tools) page lists them |
| Skills | Twelve sets of instructions the AI follows for common media tasks: which model fits, which inputs it takes, which tool to call. See [Skills](#skills) |

The connector alone gives you every tool and card; the skills help the AI choose the right model and inputs. To add only the connector, see [MCP Server](/mcp-server#connect) or, for Claude, [Use each::labs in Claude](/mcp-server/claude-chat#add-the-connector).

The plugin is installed from its own marketplace, [`eachlabs/plugin`](https://github.com/eachlabs/plugin) on GitHub. The same marketplace serves Claude and Codex.

## Add the plugin

<Tabs>
  <Tab title="claude.ai and Claude Desktop">
    The steps are the same in the browser and in the desktop app. **Customize** is the page that holds your connectors, skills and plugins.

    <Steps>
      <Step title="Open Customize > Plugins">
        Go to **Customize > Plugins**.
      </Step>
      <Step title="Add the each::labs marketplace">
        Select **Add > Add marketplace** and enter `eachlabs/plugin`.
      </Step>
      <Step title="Add the plugin">
        Open the **each::labs** plugin and select **Add**.
      </Step>
      <Step title="Connect the connector">
        Adding a plugin does not sign you in. Open the plugin's **Connectors** tab. If the each::labs connector shows **Not added**, add it there, then select **Connect**. The each::labs consent page opens; see [First sign-in](/mcp-server/claude-chat#first-sign-in).
      </Step>
    </Steps>

    The skills load whether or not you connect, but they cannot reach each::labs until the connector shows **Connected**. A plugin added here is saved to your account, so it is also available in Claude Code when you sign in there with the same account.
  </Tab>
  <Tab title="Claude Code">
    From your shell:

    ```bash
    claude plugin marketplace add eachlabs/plugin
    claude plugin install eachlabs@eachlabs
    ```

    Inside a Claude Code session, the same commands are `/plugin marketplace add eachlabs/plugin` and `/plugin install eachlabs@eachlabs`. Then run `/mcp`, select `eachlabs` and sign in when prompted; see [First sign-in](/mcp-server/claude-chat#first-sign-in).
  </Tab>
  <Tab title="Codex app">
    Add the marketplace from your shell:

    ```bash
    codex plugin marketplace add eachlabs/plugin
    ```

    Then open **Plugins** in the Codex app and install the **each::labs** plugin. If Codex does not ask you to sign in, run `codex mcp login eachlabs`. The sign-in works as described under [First sign-in](/mcp-server/claude-chat#first-sign-in).
  </Tab>
  <Tab title="Codex CLI">
    ```bash
    codex plugin marketplace add eachlabs/plugin
    codex plugin add eachlabs@eachlabs
    codex mcp login eachlabs
    ```

    The last command opens the each::labs sign-in page in your browser; see [First sign-in](/mcp-server/claude-chat#first-sign-in).
  </Tab>
</Tabs>

Every run is billed to the each::labs organization you choose at sign-in, as with the connector alone.

Cards show in apps with a chat interface: claude.ai, Claude Desktop and the Codex app. Claude Code and Codex CLI run in a terminal and have no cards; there the AI gives results as links and asks you in the chat for anything a card would collect.

## Updates

| App | How a new version arrives |
| --- | --- |
| claude.ai, Claude Desktop | Select **Check for updates** on the each::labs marketplace under **Customize > Plugins**, or turn on **Sync automatically** for it. Once a new version has synced, your account has it, with nothing to accept |
| Claude Code | Auto-update is off for marketplaces other than Anthropic's own. Turn it on for `eachlabs` under `/plugin`, on the **Marketplaces** tab, or update by hand with `claude plugin update eachlabs@eachlabs`, then run `/reload-plugins` |
| Codex | Run `codex plugin marketplace upgrade` |

Changes to the cards and tools come from the each::labs server, not from the plugin, so they reach you without a plugin update.

## Team and Enterprise plans

On Claude Team and Enterprise plans, an Owner can add the connector `https://mcp.eachlabs.ai/mcp` once for the whole organization, as [Team and Enterprise plans](/mcp-server/claude-chat#team-and-enterprise-plans) describes. Each member then adds the `eachlabs/plugin` marketplace and the plugin themselves, and signs in with their own each::labs account.

That account must belong to the each::labs organization that should pay for the runs. A member who signs in with a personal account is billed there instead.

## Skills

The AI loads a skill when your request matches its description. In Claude, you can also type `/` in the message box and choose one.

| Skill | Use it for |
| --- | --- |
| `eachlabs-image-generation` | New images from a text prompt: Flux, GPT Image, Gemini, Imagen, Seedream and other model families |
| `eachlabs-image-edit` | Editing an existing image: style transfer, background removal, upscaling, inpainting, virtual try-on, 3D, analysis |
| `eachlabs-video-generation` | New videos from text, images or reference inputs: transitions, motion control, talking head, avatars |
| `eachlabs-video-edit` | Editing an existing video: lip sync, translation, subtitles, audio merge, style transfer, extension |
| `eachlabs-music` | Songs, instrumentals, lyrics and podcasts; song extension, stem separation, song recognition |
| `eachlabs-voice-audio` | Text to speech, transcription with speaker labels, voice conversion |
| `eachlabs-face-swap` | Swapping faces between images |
| `eachlabs-fashion-ai` | Fashion model imagery, virtual try-on, runway videos, campaign visuals |
| `eachlabs-product-visuals` | Product photography and videos for e-commerce: product shots, background replacement, lifestyle scenes, 360-degree views |
| `eachlabs-workflows` | Running a workflow your organization built and reading its executions |
| `gpt-image-v2` | OpenAI GPT Image v2 for text to image and instruction-based edits |
| `bytedance-seedance-2-0` | ByteDance Seedance 2.0 for video with native audio, from text or from an image |

[Use each::labs in Claude](/mcp-server/claude-chat#what-you-can-ask) shows what to ask and what the cards look like.

## Remove it

| App | How |
| --- | --- |
| claude.ai, Claude Desktop | **Customize > Plugins**, open the plugin, open its menu and select **Remove**. The connector stays under **Customize > Connectors** until you remove it there |
| Claude Code | `claude plugin uninstall eachlabs@eachlabs` |
| Codex | `codex plugin remove eachlabs@eachlabs` |
