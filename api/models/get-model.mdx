title: "Get Model"
description: "Retrieve detailed information about a specific AI model."
---

## Endpoint

```
GET https://api.eachlabs.ai/v1/models/{slug}
```

<Note>This endpoint does not require authentication.</Note>

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `slug` | string | Yes | Model slug identifier (e.g., `flux-1-1-pro`) |

## Code Examples

<CodeGroup>
```bash cURL
curl "https://api.eachlabs.ai/v1/models/flux-1-1-pro" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api.eachlabs.ai/v1/models/flux-1-1-pro",
    headers={"Authorization": "Bearer YOUR_API_KEY"}
)

model = response.json()
print(f"Model: {model['title']}")
print(f"Input schema: {model['request_schema']}")
```

```javascript JavaScript
const response = await fetch(
  "https://api.eachlabs.ai/v1/models/flux-1-1-pro",
  {
    headers: { "Authorization": "Bearer YOUR_API_KEY" },
  }
);
const model = await response.json();
console.log(`Model: ${model.title}`);
```
</CodeGroup>

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `title` | string | Human-readable model name |
| `slug` | string | Unique model identifier |
| `version` | string | Model version |
| `output_type` | string | Output type (`string`, `array`, `object`) |
| `request_schema` | object | JSON Schema defining valid input parameters |
| `cost` | object \| null | Nullable pricing guidance; `null` means the model has no pricing document |

### Cost Estimate

When `cost` is non-null, it contains these fields:

| Field | Type | Description |
|-------|------|-------------|
| `currency` | string | Always `USD` |
| `type` | string | `fixed` or `usage_based` |
| `amount` | number \| null | Estimated USD amount for fixed pricing; otherwise `null` |
| `unit` | string \| null | `execution`, `second`, `processing_second`, `minute`, `hour`, `image`, `megapixel`, `million_tokens`, `character`, `step`, or `generation`; `null` when no public rate is listed |
| `estimate` | string | Presentation-ready guidance: a fixed amount, a safely recognized usage rate/range or billing driver, or the `Usage-based pricing` fallback |
| `description` | string | `Pricing is an estimate and may change as rates are updated.` |
| `min` | number \| null | Minimum estimated USD amount per unit for usage-based pricing; otherwise `null` |
| `max` | number \| null | Maximum estimated USD amount per unit for usage-based pricing; otherwise `null` |
| `depends_on` | string[] | Inputs that change the price, such as resolution or duration, in the order row labels list them; may be empty |
| `rows` | object[] | Price per option combination as `{label, value}` entries in USD per `unit`; see [Reading rows](#reading-rows); may be empty |

```json Usage-based
  "description": "Pricing is an estimate and may change as rates are updated.",
  "min": 0.03,
  "max": 0.14,
  "depends_on": ["resolution", "audio"],
  "rows": [

    {"label": "1080p", "value": 0.12},
    {"label": "+ audio", "value": 0.02}
  ]
}
```
</CodeGroup>

`cost` is planning guidance, not a quote for a particular input or the final
charge. For usage-based pricing, `min` and `max` are rates per `unit`, not the
minimum and maximum total price of a request. Estimates may change when model
pricing changes. Use `metrics.cost` on the resulting prediction or workflow
execution for the settled value.

### Reading rows

`rows` gives the price of each option combination, so you can estimate a request before you send it.

- A base row's label lists the option values in `depends_on` order, joined by ` · `, such as `720p · 5 s`. Its `value` is the price per `unit` for that combination.
- A label that starts with `+ ` is an add-on, such as `+ audio`. Its `value` is added to the base row when the request turns that option on. When an add-on has its own unit, the label names it, such as `+ each input image`.
- The label that ends in ` (default)` is the combination used when you leave the inputs unset.

To estimate a request, take the base row that matches its options (or the default row), add each `+ ` row the request turns on, and multiply by the quantity of `unit`: seconds of output, images, or one generation or execution. With the usage-based example above, 10 seconds at 1080p with audio is about (0.12 + 0.02) × 10 = $1.40. Some models still show older labels, such as `default`, while their rows are updated.

`Usage-based pricing` with `unit`, `amount`, `min`, and `max` all `null` means
no reliable public rate is listed. It does not mean the model is free. A free
model instead has `type: "fixed"`, `amount: 0`, and `estimate: "Free"`.

Render `estimate` for a readable summary and use the structured fields when
you need rates or tier details. Treat a missing numeric estimate as unknown;
do not substitute zero.

## Error Responses

| Status | Body | Description |
|--------|------|-------------|
| `404` | `{"error": "Failed to fetch model: model not found"}` | Model with this slug doesn't exist |
| `500` | `{"error": "Failed to fetch models: internal error"}` | Server error |
