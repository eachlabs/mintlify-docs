title: "Get Model"

## Endpoint

```
GET https://api.eachlabs.ai/v1/model
```

<Note>
  The preferred `GET /v1/models/{slug}` path returns the identical response,
  including `cost`. The query-parameter route remains available for backwards
  compatibility.
</Note>

## Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `slug` | string | Yes | Model slug identifier (e.g., `flux-1-1-pro`) |

## Code Examples

<CodeGroup>
```bash cURL
curl "https://api.eachlabs.ai/v1/model?slug=flux-1-1-pro" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api.eachlabs.ai/v1/model",
    params={"slug": "flux-1-1-pro"},
    headers={"Authorization": "Bearer YOUR_API_KEY"}
)

model = response.json()
print(f"Model: {model['title']}")
print(f"Input schema: {model['request_schema']}")
```

```javascript JavaScript
const response = await fetch(
  "https://api.eachlabs.ai/v1/model?slug=flux-1-1-pro",
  {
    headers: { "Authorization": "Bearer YOUR_API_KEY" },
  }
);
const model = await response.json();
console.log(`Model: ${model.title}`);
```
</CodeGroup>

```json
  "version": "1.0",
  "output_type": "string",

    "type": "object",
    "required": ["prompt"],
    "properties": {
      "prompt": {
        "type": "string",
        "minLength": 10,
        "maxLength": 500
      }
    }
  },
  "cost": {
    "currency": "USD",
    "type": "fixed",
    "amount": 0.04,
    "unit": "execution",
    "estimate": "$0.04 per execution",
    "description": "Pricing is an estimate and may change as rates are updated.",
    "min": null,
    "max": null,
    "depends_on": [],
    "rows": []
  }

```

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `title` | string | Human-readable model name |
| `slug` | string | Unique model identifier |
| `version` | string | Model version |
| `output_type` | string | Output type (`string`, `array`, `object`) |
| `request_schema` | object | JSON Schema defining valid input parameters |
| `cost` | object \| null | Nullable pricing guidance; `null` means the model has no pricing document |

### Cost Estimate

When `cost` is non-null, it contains exactly these fields:

| Field | Type | Description |
|-------|------|-------------|
| `currency` | string | Always `USD` |
| `type` | string | `fixed` or `usage_based` |
| `amount` | number \| null | Estimated USD amount for fixed pricing; otherwise `null` |
| `unit` | string \| null | `execution`, `second`, `processing_second`, `minute`, `hour`, `image`, `megapixel`, `million_tokens`, `character`, `step`, or `generation`; `null` when no public rate is listed |
| `estimate` | string | Presentation-ready guidance: a fixed amount, a safely recognized usage rate/range or billing driver, or the `Usage-based pricing` fallback |
| `description` | string | `Pricing is an estimate and may change as rates are updated.` |
| `min` | number \| null | Minimum estimated USD amount per unit for usage-based pricing; otherwise `null` |
| `max` | number \| null | Maximum estimated USD amount per unit for usage-based pricing; otherwise `null` |
| `depends_on` | string[] | Input names that determine the estimate; may be empty |
| `rows` | object[] | Optional price breakdown as `{label, value}` entries; may be empty |

<CodeGroup>
```json Fixed
{
  "currency": "USD",
  "type": "fixed",
  "amount": 0.04,
  "unit": "execution",
  "estimate": "$0.04 per execution",
  "description": "Pricing is an estimate and may change as rates are updated.",
  "min": null,
  "max": null,
  "depends_on": [],
  "rows": []
}
```

```json Usage-based
{
  "currency": "USD",
  "type": "usage_based",
  "amount": null,
  "unit": "second",
  "estimate": "$0.03–$0.12 per second, depending on resolution",
  "description": "Pricing is an estimate and may change as rates are updated.",
  "min": 0.03,
  "max": 0.12,
  "depends_on": ["resolution"],
  "rows": [
    {"label": "480p", "value": 0.03},
    {"label": "1080p", "value": 0.12}
  ]
}
```
</CodeGroup>

`Usage-based pricing` means no public rate is listed, and the final cost is
returned as `metrics.cost` on the resulting prediction or workflow execution.

## Error Responses

| Status | Body | Description |
|--------|------|-------------|
| `400` | `{"error": "slug parameter is required"}` | Missing `slug` parameter |
| `404` | `{"error": "Failed to fetch model: model not found"}` | Model with this slug doesn't exist |
| `500` | `{"error": "Failed to fetch models: internal error"}` | Server error |
