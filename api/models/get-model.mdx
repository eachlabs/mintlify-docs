title: "Get Model"
description: "Retrieve detailed information about a specific AI model."

## Endpoint

```
GET https://api.eachlabs.ai/v1/model
```

<Note>
  The preferred `GET /v1/models/{slug}` path returns the identical response,
  including `cost`. The query-parameter route remains available for backwards
  compatibility.
</Note>

## Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `slug` | string | Yes | Model slug identifier (e.g., `flux-1-1-pro`) |

## Code Examples

<CodeGroup>
```bash cURL
curl "https://api.eachlabs.ai/v1/model?slug=flux-1-1-pro" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api.eachlabs.ai/v1/model",
    params={"slug": "flux-1-1-pro"},
    headers={"Authorization": "Bearer YOUR_API_KEY"}
)

model = response.json()
print(f"Model: {model['title']}")
print(f"Input schema: {model['request_schema']}")
```

```javascript JavaScript
const response = await fetch(
  "https://api.eachlabs.ai/v1/model?slug=flux-1-1-pro",
  {
    headers: { "Authorization": "Bearer YOUR_API_KEY" },
  }
);
const model = await response.json();
console.log(`Model: ${model.title}`);
```
</CodeGroup>

## Response

```json
{
  "title": "Flux 1.1 Pro",
  "slug": "flux-1-1-pro",
  "version": "1.0",
  "output_type": "string",
  "request_schema": {
    "type": "object",
    "required": ["prompt"],
    "properties": {
      "prompt": {
        "type": "string",
        "minLength": 10,
        "maxLength": 500
      }
    }
  },
  "cost": {
    "currency": "USD",
    "type": "estimated",
    "billing_model": "dynamic",
    "rules": {
      "type": "dynamic",
      "variables": {
        "duration": "output.duration"
      },
      "rules": [
        {
          "when": [],
          "formula": {
            "expr": "duration * 0.05",
            "params": {}
          }
        }
      ]
    }
  }
}
```

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `title` | string | Human-readable model name |
| `slug` | string | Unique model identifier |
| `version` | string | Model version |
| `output_type` | string | Output type (`string`, `array`, `object`) |
| `request_schema` | object | JSON Schema defining valid input parameters |
| `cost` | object \| null | Always-present rule-backed estimate, or `null` when production pricing rules are unavailable or unusable |

### Cost Estimate

When `cost` is non-null, it contains exactly these fields:

| Field | Type | Description |
|-------|------|-------------|
| `currency` | string | Always `USD` |
| `type` | string | Always `estimated` |
| `billing_model` | string | Always `dynamic` |
| `rules` | object | Parsed production pricing rules, preserved structurally |

The estimate does not calculate a scalar amount before execution. For the final
settled value, use `metrics.cost` in the resulting prediction or workflow
execution.

## Error Responses

| Status | Body | Description |
|--------|------|-------------|
| `400` | `{"error": "slug parameter is required"}` | Missing `slug` parameter |
| `404` | `{"error": "Failed to fetch model: model not found"}` | Model with this slug doesn't exist |
| `500` | `{"error": "Failed to fetch models: internal error"}` | Server error |
