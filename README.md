# mintlify-docs

Public eachlabs documentation site (Mintlify). See `AGENTS.md` for structure, commands, and CI.

## LLM Router model list

There is no hand-maintained or generated model table any more: `GET /v1/llm-router/models` (documented under the OpenAPI reference, examples on `llm-router/overview.mdx`) is the list, served from the router's catalog. Do not add a static model table back.
