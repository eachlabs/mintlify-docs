LLM Router gives you every chat model on [OpenRouter](https://openrouter.ai/models) through a single, OpenAI-compatible API. Smart routing, automatic failover, caching, cost optimization. One base URL to rule them all.

```
https://api.eachlabs.ai/v1
```

## Supported Providers

| Provider | Example Models |
|----------|---------------|
| OpenAI | `openai/gpt-5.6-sol`, `openai/gpt-5.6-luna` |
| Anthropic | `anthropic/claude-sonnet-4.6`, `anthropic/claude-haiku-4.5` |
| Google | `google/gemini-3.5-flash`, `google/gemini-3.1-pro-preview` |
| Meta | `meta-llama/llama-4-maverick` |
| DeepSeek | `deepseek/deepseek-v4-pro`, `deepseek/deepseek-chat` |
| Mistral | `mistralai/mistral-large` |
| Qwen | `qwen/qwen3-max` |

<Note>
  This is just a taste. Any chat model ID from [OpenRouter's model list](https://openrouter.ai/models) works. See [Available Models](/llm-router/models) for the full list with prices.
</Note>

## Model Format

Models use the `provider/model-name` format:

```
openai/gpt-5.6-sol
anthropic/claude-sonnet-4.6
google/gemini-3.5-flash
deepseek/deepseek-v4-pro
```

## How It Works

<Steps>
  <Step title="Send a request">
    Make an OpenAI-compatible API call to `https://api.eachlabs.ai/v1` with your each::labs API key. That's it.
  </Step>
  <Step title="LLM Router does its thing">
    Validates your request, checks the cache, picks the best provider. All in milliseconds.
  </Step>
  <Step title="Get your response">
    Standard OpenAI-compatible response. Works with any SDK or framework that speaks OpenAI.
  </Step>
</Steps>

## Pricing

You only pay for the tokens you use: the model's list price plus the same standard <Tooltip tip="5.5%, OpenRouter's standard credit fee.">platform fee</Tooltip> OpenRouter charges, nothing more. See list prices on the [Available Models](/llm-router/models) page and the exact cost of every request in your [dashboard](https://www.eachlabs.ai).
