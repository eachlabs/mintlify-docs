Pass any chat model ID from [OpenRouter's model list](https://openrouter.ai/models) as the `model` parameter. The tables below start with our <Tooltip tip="Models we have reviewed and documented, each with its own page.">featured models</Tooltip>, followed by every other <Tooltip tip="Any other chat model OpenRouter publishes. It works the same way, with the same pricing.">available model</Tooltip>.

```python
response = client.chat.completions.create(
    model="openai/gpt-5.6-sol",  # any model ID from the tables below
    messages=[{"role": "user", "content": "Hello!"}]
)
```

## How it works

- **Send the exact ID.** Use the value in the *Model ID* column. When a featured model's ID differs from OpenRouter's, the matching <Tooltip tip="The ID OpenRouter uses for the same model, shown so you can match the two lists.">OpenRouter ID</Tooltip> is shown next to its name.
- **Pricing.** You pay the model's list price plus the same standard <Tooltip tip="5.5%, OpenRouter's standard credit fee.">platform fee</Tooltip> OpenRouter charges, nothing more. The exact cost of every request is shown in your [dashboard](https://www.eachlabs.ai).
- **Not available.** Free (`:free`) variants of non-featured models. Audio and Decisions have their own model lists: see [Audio](/llm-router/audio) and [Decisions](/llm-router/decisions).
- **Unknown or unavailable IDs** return a `400` error that names the model.
- **Model catalog as JSON.** The [Model catalog API](/llm-router/model-catalog) returns the featured models.
