## 1. Create a workflow

This workflow has two steps: an LLM turns a short idea into a detailed prompt, then an image model
draws it.

```bash
curl -X POST https://api.eachlabs.ai/v1/workflows \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "name": "Text to Image Generator",
    "definition": {
      "input_schema": {
        "properties": {
          "prompt": { "type": "string", "required": true }
        }
      },
      "steps": [
        {
          "id": "write_prompt",
          "type": "model",
          "model": "eachlabs-llm-router",
          "params": {
            "model": "google/gemini-3.6-flash",
            "messages": [
              { "role": "system", "content": "Rewrite the idea as one vivid, detailed image prompt. Reply with the prompt only." },
              { "role": "user", "content": "$.inputs.prompt" }
            ]
          }
        },
        {
          "id": "generate_image",
          "type": "model",
          "model": "nano-banana-2-text-to-image",
          "params": {
            "prompt": "$.write_prompt.primary.choices[0].message.content",
            "aspect_ratio": "16:9"
          }
        }
      ]
    }
  }'
```

`$.inputs.prompt` is the workflow input. `$.write_prompt.primary.choices[0].message.content` is the
text the LLM step returned. See [parameter references](/workflows/concepts/parameter-references).

Response:

```json
{
  "workflow_id": "50741f40-8621-4d46-8a91-dff4d873be98",
  "slug": "text-to-image-generator",
  "name": "Text to Image Generator",
  "status": "active",
  "versions": [
    {
      "version_id": "v1",
      "slug": "text-to-image-generator",
      "status": "active"
    }
  ]
}
```

## 2. Run it

```bash
curl -X POST https://api.eachlabs.ai/v1/workflows/trigger/50741f40-8621-4d46-8a91-dff4d873be98/v1 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "inputs": {
      "prompt": "A lighthouse on a cliff at sunset"
    }
  }'
```

Response:

```json
{
  "execution_id": "e2dba2bb-bc1d-4651-b6bf-fbbbebdee104",
  "status": "queued"
}
```

## 3. Read the result

Poll until `status` is `completed`, `failed` or `cancelled`:

```bash
curl https://api.eachlabs.ai/v1/workflows/executions/e2dba2bb-bc1d-4651-b6bf-fbbbebdee104 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Response (shortened):

```json
{
  "execution_id": "e2dba2bb-bc1d-4651-b6bf-fbbbebdee104",
  "workflow_id": "50741f40-8621-4d46-8a91-dff4d873be98",
  "status": "completed",
  "output": "https://cdn-us.eachlabs.ai/uploads/3334048f.png",
  "step_outputs": {
    "write_prompt": {
      "step_id": "write_prompt",
      "status": "completed",
      "primary": { "choices": [{ "message": { "content": "A dramatic wide-angle photograph of a weather-beaten lighthouse..." } }] }
    },
    "generate_image": {
      "step_id": "generate_image",
      "status": "completed",
      "output": "https://cdn-us.eachlabs.ai/uploads/3334048f.png",
      "primary": "https://cdn-us.eachlabs.ai/uploads/3334048f.png"
    }
  }
}
```

`output` is the result of the last step.
