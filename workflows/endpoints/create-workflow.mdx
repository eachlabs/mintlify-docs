## Endpoint

```
POST https://api.eachlabs.ai/v1/workflows
```

## Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | Yes | Human-readable workflow name |
| `definition` | object | No | Workflow definition with steps and input schema. Creates version `v1` (or the name in `definition.version`) |

### Definition Object

| Field | Type | Description |
|-------|------|-------------|
| `steps` | array | Steps to run; each needs a unique `id`. See [workflow structure](/workflows/concepts/workflow-structure) |
| `input_schema` | object | Inputs under `properties`, each with `type`, `required` and an optional `default_value` |
| `metadata` | object | Optional; `metadata.output_mapping` names values in the run's `workflow_output` |
| `version` | string | Optional name of the first version (default `"v1"`) |

New workflows are private. Model names and parameters are checked when a step runs, not when the
workflow is saved, so run a new workflow once before relying on it.

## Code Examples

<CodeGroup>
```bash cURL
curl -X POST https://api.eachlabs.ai/v1/workflows \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "name": "Image Generator",
    "definition": {
      "input_schema": {
        "properties": {
          "prompt": { "type": "string", "required": true }
        }
      },
      "steps": [
        {
          "id": "generate",
          "type": "model",
          "model": "nano-banana-2-text-to-image",
          "params": { "prompt": "$.inputs.prompt", "aspect_ratio": "1:1" }
        }
      ]
    }
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.eachlabs.ai/v1/workflows",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json={
        "name": "Image Generator",
        "definition": {
            "input_schema": {
                "properties": {"prompt": {"type": "string", "required": True}}
            },
            "steps": [
                {
                    "id": "generate",
                    "type": "model",
                    "model": "nano-banana-2-text-to-image",
                    "params": {"prompt": "$.inputs.prompt", "aspect_ratio": "1:1"},
                }
            ],
        },
    },
)

workflow = response.json()
print(f"Created: {workflow['workflow_id']}")
```

```javascript JavaScript
const response = await fetch("https://api.eachlabs.ai/v1/workflows", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer YOUR_API_KEY",
  },
  body: JSON.stringify({
    name: "Image Generator",
    definition: {
      input_schema: {
        properties: { prompt: { type: "string", required: true } },
      },
      steps: [
        {
          id: "generate",
          type: "model",
          model: "nano-banana-2-text-to-image",
          params: { prompt: "$.inputs.prompt", aspect_ratio: "1:1" },
        },
      ],
    },
  }),
});

const workflow = await response.json();
console.log(`Created: ${workflow.workflow_id}`);
```

## Error Responses

| Status | Body | Description |
|--------|------|-------------|
| `400` | `{"error": "name is required"}` | Missing required fields |
| `400` | `{"error": "invalid argument"}` | The definition failed validation. Send it to [Create/Update Version](/workflows/endpoints/create-version) to see the exact reason |
| `401` | `{"error": "Invalid or missing API key"}` | Authentication failure |
