## Endpoint

```
GET https://api.eachlabs.ai/v1/workflows/{workflowID}/executions
```

Rows carry each run's inputs and result but omit the per-step payloads — fetch a [single execution](/workflows/endpoints/get-execution) for `step_outputs` and the full `output`.

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `workflowID` | string | Yes | Workflow UUID or slug |

## Query Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `bulk_id` | string (UUID) | No | `-` | Filter by bulk operation ID |
| `execution_ids` | string | No | `-` | Restrict to specific executions. Comma-separated, or repeat the parameter |
| `offset` | integer | No | `0` | Number of items to skip |
| `limit` | integer | No | `50` | Max results per page (1–100) |

`bulk_id` and `execution_ids` compose with each other and with pagination.

## Code Examples

<CodeGroup>
```bash cURL
# List all executions
curl "https://api.eachlabs.ai/v1/workflows/WF_ID/executions?limit=10" \
  -H "X-API-Key: YOUR_API_KEY"

# Filter by bulk ID
curl "https://api.eachlabs.ai/v1/workflows/WF_ID/executions?bulk_id=BULK_ID" \
  -H "X-API-Key: YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api.eachlabs.ai/v1/workflows/WF_ID/executions",
    params={"limit": 10},
    headers={"X-API-Key": "YOUR_API_KEY"}
)

data = response.json()
for execution in data["executions"]:
    print(f"{execution['execution_id']} | {execution['status']}")
print(f"Total: {data['total_count']}")
```

```javascript JavaScript
const response = await fetch(
  "https://api.eachlabs.ai/v1/workflows/WF_ID/executions?limit=10",
  { headers: { "X-API-Key": "YOUR_API_KEY" } }
);
const data = await response.json();

data.executions.forEach((e) => {
  console.log(`${e.execution_id} | ${e.status}`);
});
console.log(`Total: ${data.total_count}`);
```
</CodeGroup>

### Execution Summary Fields

| Field | Type | Description |
|-------|------|-------------|
| `execution_id` | string | Unique execution ID |
| `workflow_id` | string | Workflow UUID |
| `workflow_name` | string | Workflow name |
| `version_id` | string | Version used |
| `bulk_id` | string \| null | Bulk operation ID, when the run came from a bulk trigger |
| `status` | string | `running`, `completed`, `failed`, or `cancelled` |
| `started_at` | string \| null | When execution started |
| `completed_at` | string \| null | When execution ended |
| `created_at` | string | When the execution was queued |
| `inputs` | object | Input parameters used |
| `output_json` | object \| null | The run's effective result |
| `total_cost` | number \| null | Summed model cost. Present only on terminal rows |

Alongside `executions`, the envelope carries `limit`, `offset`, and `total_count` (total matching executions).

## Error Responses

| Status | Description |
|--------|-------------|
| `400` | Malformed filter value |
| `401` | Invalid or missing API key |
| `404` | Workflow not found, or owned by another organization |
| `408` | Request timed out |
| `502` | Workflows Engine unavailable |
