## Endpoint

```
PUT https://api.eachlabs.ai/v1/workflows/{workflowID}
```

<Note>
  This renames the workflow only. To update the definition (steps), use [Create Version](/workflows/endpoints/create-version).
</Note>

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `workflowID` | string | Yes | Workflow UUID or slug |

## Request Body

`name` is the only field this endpoint honors. Any other key you send is ignored.

| Field | Type | Description |
|-------|------|-------------|
| `name` | string | Updated workflow name |

<Warning>
  A real rename regenerates the workflow slug. Any URL that pins the old slug — including public workflow links — stops resolving.
</Warning>

## Code Examples

<CodeGroup>
```bash cURL
curl -X PUT https://api.eachlabs.ai/v1/workflows/WF_ID \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "name": "Text to Image Generator v2"
  }'
```

```python Python
import requests

response = requests.put(
    "https://api.eachlabs.ai/v1/workflows/WF_ID",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={"name": "Text to Image Generator v2"}
)
print(response.json())
```

```javascript JavaScript
const response = await fetch(
  "https://api.eachlabs.ai/v1/workflows/WF_ID",
  {
    method: "PUT",
    headers: {
      "Content-Type": "application/json",
      "Authorization": "Bearer YOUR_API_KEY",
    },
    body: JSON.stringify({
      name: "Text to Image Generator v2",
    }),
  }
);
console.log(await response.json());
```
</CodeGroup>

## Error Responses

| Status | Body | Description |
|--------|------|-------------|
| `400` | `{"error": "invalid JSON body"}` | Malformed or empty request body |
| `401` | `{"error": "Invalid or missing API key"}` | Authentication failure |
| `403` | `{"error": "forbidden"}` | Not allowed to modify this workflow |
| `404` | `{"error": "workflow not found"}` | Invalid workflow ID |
| `409` | `{"error": "conflict"}` | The new name resolves to a slug already taken by another workflow |
