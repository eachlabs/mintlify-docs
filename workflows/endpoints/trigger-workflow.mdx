## Endpoint

```
POST https://api.eachlabs.ai/v1/workflows/trigger/{workflowID}/{versionID}
```

The workflow executes asynchronously. You'll get an execution ID right away, then you can poll or use webhooks to grab the results.

<Note>
  The version is pinned in the path — there's no unversioned form. Trigger the version you mean.
</Note>

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `workflowID` | string | Yes | Workflow UUID or slug |
| `versionID` | string | Yes | Version to run (e.g. `v1`) |

## Request Body

The body is optional — omit it for a workflow that takes no inputs.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `inputs` | object | No | Input values matching the workflow version's input schema |
| `webhook_url` | string | No | URL to receive the completion notification |
| `webhook_secret` | string | No | Secret used to sign the webhook request |

`webhook_url` is also accepted as a query parameter for compatibility. The body field wins when both are present.

## Code Examples

<CodeGroup>
```bash cURL
curl -X POST https://api.eachlabs.ai/v1/workflows/trigger/WF_ID/v1 \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{
    "inputs": {
      "prompt": "A majestic mountain landscape"
    },
    "webhook_url": "https://your-app.com/webhooks/workflow"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.eachlabs.ai/v1/workflows/trigger/WF_ID/v1",
    headers={
        "Content-Type": "application/json",
        "X-API-Key": "YOUR_API_KEY"
    },
    json={
        "inputs": {"prompt": "A majestic mountain landscape"},
        "webhook_url": "https://your-app.com/webhooks/workflow"
    }
)

data = response.json()
print(f"Execution ID: {data['execution_id']}")
```

```javascript JavaScript
const response = await fetch(
  "https://api.eachlabs.ai/v1/workflows/trigger/WF_ID/v1",
  {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "X-API-Key": "YOUR_API_KEY",
    },
    body: JSON.stringify({
      inputs: { prompt: "A majestic mountain landscape" },
      webhook_url: "https://your-app.com/webhooks/workflow",
    }),
  }
);
const { execution_id } = await response.json();
console.log(`Execution ID: ${execution_id}`);
```
</CodeGroup>

## Response

**Status: `202 Accepted`**

```json
{
  "execution_id": "e2dba2bb-bc1d-4651-b6bf-fbbbebdee104",
  "status": "queued"
}
```

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `execution_id` | string | Unique execution ID for tracking |
| `status` | string | `"queued"`, meaning the execution has been queued |

The response only confirms the run was queued. From there the execution moves through `running` to a terminal `completed`, `failed`, or `cancelled`.

## Error Responses

| Status | Description |
|--------|-------------|
| `400` | Input validation failure |
| `401` | Invalid or missing API key |
| `402` | Insufficient balance |
| `404` | Workflow or version not found |
| `408` | Request timed out |
| `502` | Workflows Engine unavailable |
